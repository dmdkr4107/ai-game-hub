# 11. 3단계 Godot 게임 제작

## 사용

- **AI 게임 만들기**에서 2D 또는 3D를 선택합니다. **문장으로 만들기**에서 `제목은 달빛 탐험, 별 5개, 어려운 난이도, 우주 테마에서 빠르게 이동하고 높게 점프`처럼 요청할 수 있습니다. **직접 설정**은 Ollama가 없어도 Godot이 준비되어 있으면 사용할 수 있습니다.
- 테마는 밤하늘·숲·우주, 이동은 느림·기본·빠른 이동과 높은 점프 중에서 선택합니다. AI 채팅에서 가져온 설정도 생성 전에 같은 양식에서 편집할 수 있습니다.
- **내 게임 → 미리 플레이**에서 앱 안에 게임을 엽니다. 게임 영역을 클릭해 키보드 입력을 시작합니다. 방향키나 WASD로 이동하고 Space로 점프합니다. 별을 모두 모은 뒤 출구에 닿으면 완료됩니다. R은 재시작, Esc는 게임 화면 닫기입니다.
- 첫 이동 또는 점프에 타이머가 시작됩니다. 게임 화면을 닫기 전까지는 R로 재도전해도 최단 완료 시간이 표시됩니다.
- **수정**에서는 자연어로 제목, 별 1~8개, 난이도, 테마, 이동을 바꿀 수 있습니다. **이전 버전 복원**은 직전 저장 버전으로 돌아갑니다. 프로젝트는 앱 사용자 데이터 폴더의 `games`에 보관됩니다.

## 처리 방식

- 서명을 확인한 Windows용 Godot 4.7.2 실행 파일로 검증했습니다. [Godot 다운로드](https://godotengine.org/download/archive/4.7.2-stable/)
- Ollama는 허용된 게임 설정을 JSON으로 제안합니다. 직접 입력과 AI 제안 모두 앱이 값을 검사합니다. 이후 2D 횡스크롤 또는 3D 발판 템플릿의 작업 사본을 만들고 숨김 Godot 검사를 실행합니다. 기존 프로젝트에 테마와 이동 항목이 없으면 밤하늘과 기본 이동을 적용합니다.
- 검사에 성공한 작업 사본에만 현재 버전 표시를 갱신합니다. 수정에 실패하면 이전 버전이 유지됩니다. 한 앱 프로필에서 동시에 실행된 동일 앱끼리 저장을 덮어쓰지 않도록 단일 인스턴스 잠금을 사용합니다.
- 템플릿을 미리 플레이할 때는 Godot Web으로 변환해 같은 앱 창의 격리된 영역에서 실행합니다. 이후 별도로 추가된 AI 자유 제작은 [개발 기록](DEV_LOG.md#2026-11-21--ai-자유-제작)에 정리했습니다.

## 세 차례 검증

| 확인 | 결과 |
|---|---|
| 자동 회귀 검사 | 1·2단계 기준 검사 27개를 구현 전에 통과했습니다. 3단계를 합친 최종 자동 검사 36개, TypeScript·Vite 빌드, 의존성 검사 0건을 확인했습니다. |
| Windows 숨김 실행 | Electron에서 2D·3D 미리보기, 로컬 채팅, 게임 생성, 미리보기 제어, 수정·복원을 확인했습니다. 실제 Ollama와 Godot으로 두 모드의 별을 3개로 생성하고, 플레이 검사 후 4개로 바꾸고 3개로 복원했습니다. 별도로 숨김 Electron UI에서 실제 자연어 입력으로 2D·3D 프로젝트를 만들고 내 게임 목록에서 확인했습니다. |
| 독립 검토 및 엔진 검증 | 별도 검토에서 저장 전 검증 조건과 동시 앱 실행 처리를 보완했습니다. 실제 Godot으로 2D·3D, 난이도 3종, 별 1·3·8개 조합 18개, 별 8개 이동·점프 완주 6개를 통과했습니다. |

Windows 설치 파일을 만들고 템플릿이 패키지 안에 포함된 것을 확인했습니다. 패키지의 `app.asar`에서 직접 읽은 두 템플릿으로도 Godot 생성 검사를 통과했습니다.

자동화는 사용자 작업을 방해하지 않도록 창을 숨겼습니다. 사람이 직접 조작하는 가시 게임 창과 설치 마법사는 이번 검증에서 열지 않았습니다. 이 PC 외의 하드웨어 성능은 미검증입니다.

## 같은 창 플레이 후속 검증

- Godot 4.7.2와 공식 Web 템플릿으로 생성된 2D·3D 게임을 실제 Windows Electron의 같은 창에서 시작했습니다. 게임을 닫으면 해당 프레임과 임시 실행 파일이 정리됩니다.
- 해당 프레임에는 앱의 파일·AI IPC가 노출되지 않습니다. 준비·실패·중지 흐름과 실행 파일 접근 범위를 자동 검사에 포함했습니다.
