# 04. 개발 1단계 상세 작업 및 완료 기준

## 목표
정상 실행되는 Windows **내부 개발용** 앱 셸, 직관적인 메뉴 이동, 확장 가능한 프로젝트 골격을 마련한다. 로컬 AI·Godot·온라인 계정은 구현하지 않는다.

## 작업 목록
| 번호 | 작업 | 기대 산출물 | 확인 방법 |
|---|---|---|---|
| 1-01 | 프로젝트 초기화, Git, 패키지 관리/스크립트 | 재현 가능한 소스 구조, 실행 명령 안내 | 새 환경 의존성 설치 후 실행 |
| 1-02 | Electron 메인/프리로드/React UI 분리 | Windows 앱 창 | 앱 단독 실행·닫기 |
| 1-03 | 홈/AI 게임 만들기/내 게임/설정 화면 | 4개 빈 상태/안내 화면 | 전 메뉴 왕복 이동 |
| 1-04 | 한국어 UI 우선, 영어 확장용 메시지 키 | 외부화된 문구 구조 | 하드코딩 점검 |
| 1-05 | 로그인·AI·게임 제작·공유 기능은 '준비 중' 처리 | 기능 상태 표시 | 미구현 기능 오동작 없음 |
| 1-06 | 최소 Electron 보안 기본값 및 IPC 허용 목록 | 보안 설정/검증 체크리스트 | `nodeIntegration=false`, `contextIsolation=true`, sandbox 및 CSP 확인 |
| 1-07 | 디렉터리 구조, 설계 문서, 로그 정책 | README + docs | 코드/문서 경로 확인 |
| 1-08 | 단위/화면 이동/앱 시작 스모크 테스트 | CI/로컬 테스트 명령 | 실제 실행 및 테스트 로그 확인 |
| 1-09 | Windows 최종 실행 점검 | 검증 기록 | Windows PC에서 직접 실행·스크린샷 확보 |

## 권장 폴더 구조(미생성, 1단계 구현 때 생성)
```text
ai-game-hub/
├─ docs/                  # 기획/아키텍처/테스트 문서
├─ src/
│  ├─ main/               # Electron 실행 계층
│  ├─ preload/            # 안전한 화면-시스템 연결
│  ├─ renderer/           # React UI
│  │  ├─ pages/           # Home, Create, MyGames, Settings
│  │  ├─ components/
│  │  └─ i18n/
│  └─ shared/             # 타입·권한·상태 공통 정의
├─ tests/
├─ assets/
├─ package.json
└─ README.md
```

## 완료 기준(모두 통과해야 1단계 완료)
- [ ] Windows 환경에서 의존성 설치 및 데스크톱 창 실행이 재현된다.
- [ ] 홈/AI 게임 만들기/내 게임/설정을 마우스·키보드로 이동할 수 있다.
- [ ] 미구현 기능이 실제 실행되는 것처럼 표시되지 않는다.
- [ ] 개발용 화면임을 명시하며, 인증 없는 서비스용 배포는 차단된다.
- [ ] 앱 UI에서 임의 시스템 명령 호출이나 파일 전체 접근을 허용하지 않는다.
- [ ] Electron 보안 기본값, CSP, IPC 경계 테스트를 기록한다.
- [ ] 테스트 결과와 알려진 문제를 README 또는 docs에 남긴다.
- [ ] 기존 사용자 파일을 삭제·덮어쓰지 않는다.
- [ ] 사용자가 1단계 결과를 확인하고 다음 단계 진행 여부를 승인한다.

## 이번 문서 작성과 1단계 완료는 다르다
**현재 1단계 구현 상태: 미착수.** 테스트: 미실행. 위 체크박스는 완료를 주장하는 항목이 아니라 이후 개발 시 확인할 기준이다.
