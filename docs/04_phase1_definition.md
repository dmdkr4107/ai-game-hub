# 04. 개발 1단계 상세 작업 및 완료 기준

## 목표
정상 실행되는 Windows **내부 개발용** 앱 셸, 직관적인 메뉴 이동, 확장 가능한 프로젝트 골격을 마련한다. 로컬 AI·Godot·온라인 계정은 구현하지 않는다.

## 작업 목록
| 번호 | 작업 | 기대 산출물 | 확인 방법 |
|---|---|---|---|
| 1-01 | 프로젝트 초기화, Git, 패키지 관리/스크립트 | 재현 가능한 소스 구조, 실행 명령 안내 | 새 환경 의존성 설치 후 실행 |
| 1-02 | Electron 메인/프리로드/React UI 분리 | Windows 앱 창 | 앱 단독 실행·닫기 |
| 1-03 | 홈/AI 게임 만들기/내 게임/설정 화면 | 4개 빈 상태/안내 화면 | 전 메뉴 왕복 이동 |
| 1-04 | 한국어 UI 우선, 영어 확장용 메시지 키 | 외부화된 문구 구조 | 하드코딩 점검 |
| 1-05 | 로그인·AI·게임 제작·공유 기능은 '준비 중' 처리 | 기능 상태 표시 | 미구현 기능 오동작 없음 |
| 1-06 | 최소 Electron 보안 기본값 및 IPC 허용 목록 | 보안 설정/검증 체크리스트 | `nodeIntegration=false`, `contextIsolation=true`, sandbox 및 CSP 확인 |
| 1-07 | 디렉터리 구조, 설계 문서, 로그 정책 | README + docs | 코드/문서 경로 확인 |
| 1-08 | 단위/화면 이동/앱 시작 스모크 테스트 | CI/로컬 테스트 명령 | 실제 실행 및 테스트 로그 확인 |
| 1-09 | Windows 최종 실행 점검 | 검증 기록 | Windows PC에서 직접 실행·스크린샷 확보 |

## 초기 설계의 권장 폴더 구조
```text
ai-game-hub/
├─ docs/                  # 기획/아키텍처/테스트 문서
├─ src/
│  ├─ main/               # Electron 실행 계층
│  ├─ preload/            # 안전한 화면-시스템 연결
│  ├─ renderer/           # React UI
│  │  ├─ pages/           # Home, Create, MyGames, Settings
│  │  ├─ components/
│  │  └─ i18n/
│  └─ shared/             # 타입·권한·상태 공통 정의
├─ tests/
├─ assets/
├─ package.json
└─ README.md
```

## 완료 기준

아래 상태는 2026-11-20 Windows 보완 검증을 기준으로 합니다.

- [x] 새 폴더에서 잠금 파일의 의존성을 설치하고, 원클릭 데스크톱 창 실행과 정상 종료를 확인했습니다.
- [x] 홈·AI 게임 만들기·내 게임·설정의 마우스·키보드 이동을 실제 Electron 스모크 테스트로 확인했습니다.
- [x] 미구현 제작·실행 기능에 준비 중 상태를 표시하고, AI 제작 버튼을 비활성화했습니다.
- [x] 앱과 설치 파일을 내부 테스트용으로 표시합니다. 저장소는 비공개이며 빌드 명령의 자동 업로드는 꺼져 있습니다.
- [x] 화면의 IPC는 읽기 전용 앱 정보만 제공하며, 렌더러에서 Node.js 시스템 API에 접근할 수 없습니다.
- [x] Electron 격리 설정, 배포본의 연결 정책과 IPC 경계를 자동 검사에 포함했습니다.
- [x] 실행 방법, 테스트 명령, 남은 검증 항목을 [README](../README.md) 및 [개발 기록](DEV_LOG.md)에 남겼습니다.
- [x] 기존 사용자 파일을 보존하고 새 Windows 설치·패키지 검증을 별도 폴더에서 진행했습니다.
- [ ] 사용자가 결과를 확인하고 2단계 진행을 승인합니다.

## 확인 범위

Windows에서 소스 실행, 개발 모드, 패키지 빌드와 압축 해제된 앱을 검증했습니다. 실제 설치 마법사는 별도 확인 항목입니다. 로그인과 서비스 배포는 후속 개발 범위입니다.
