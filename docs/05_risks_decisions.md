# 05. 위험, 정책 결정 대기, 기술 근거

## 우선순위별 위험
| 등급 | 위험 | 대응 / 통과 조건 |
|---|---|---|
| 심각 | AI 생성 게임 또는 남의 게임의 악성 코드 | 작업 디렉터리·실행권한·네트워크 제한, Windows 격리 검증, 침투 테스트 통과 전 공유 게임 플레이 금지 |
| 심각 | 로그인 필수 정책과 1~3단계 미로그인 데모 | 내부 개발용으로만 사용, 4단계 인증/권한 전 공개 배포 금지; P0 인증 시험 일정은 승인 필요 |
| 높음 | 모델 성능 편차/GPU 경합/저장 공간 | 저중고 사양 실측, 큐·리소스 예산, 미지원 안내 |
| 높음 | 법률·아동 안전·연령별 채팅 | 출시국별 보호자 동의/등급/신고 운영 검토; 미충족 지역 출시 보류 |
| 높음 | 코드 자동 생성의 품질·복구 실패 | 검증된 템플릿, 작업본→테스트→승격, 복구 지점, 제한된 재시도 |
| 높음 | 유료 서비스 없이 무한 무료 공유 비용 | 파일 크기·트래픽·심사/운영비 측정, 수익화 임의 확정 금지 |
| 높음 | 콘텐츠·에셋 라이선스/리믹스 분쟁 | 출처·허용 범위 기록, 약관/법률 검토 |
| 중간 | 서버 장애/네트워크 끊김 | 로컬 쓰기 안전 종료, 재접속 안내, 오프라인 기능 사용은 차단 |
| 중간 | 사용자 호스트 멀티플레이 NAT·치트·호스트 이탈 | P2 실측 전 네트워크 방식 확정 금지 |

## 당장 필요한 사용자 승인(실행을 위한 질문)
1. **1단계 개발 시작 승인 여부**: 이번 요청은 문서 작성만 포함; 1단계 코드는 아직 작성하지 않았다.
2. **내부 개발 전용 UI 범위 승인 여부**: 정식 로그인은 4단계 구현 계획이므로, 1단계 화면은 내부용에 한정하고 제작·공유 버튼을 '준비 중'으로 처리하는 것을 제안한다.
3. **원문 P0의 로그인 시험과 단계 4 인증 일정 충돌 조정 여부**: 내부 P0 완료 전에 최소 인증 통합 시험을 당겨 수행할지 추후 결정.

위 외의 OPEN 항목은 지금 즉시 결정할 필요가 없으며 임의 확정하지 않는다.
