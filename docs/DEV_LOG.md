# AI Game Hub 개발 기록

## 현재 범위

Electron, React, TypeScript로 만드는 Windows 게임 제작 플랫폼입니다. 1단계는 내부 개발용 UI 프로토타입입니다. 2단계 로컬 AI 연동은 사용자 승인 후 시작합니다.

## 2026-11-20 — 요구사항 대화에서 Windows 실행 검증까지

- 기존 ChatGPT 대화에서 요구사항 분석, 아키텍처, 단계별 로드맵과 1단계 완료 기준을 정리했습니다. 자세한 내용은 [설계 문서 모음](README.md)에 있습니다.
- 1단계에 홈, AI 게임 만들기, 내 게임, 설정을 구현했습니다. 제작 화면에서 2D·3D 선택과 예시 입력을 체험할 수 있으며, AI 제작 버튼은 준비 중 상태입니다.
- Windows 원클릭 실행 중 `ERR_FILE_NOT_FOUND`와 검은 화면이 보고되어 개발 서버로 우회했습니다. Codex에서 동일한 폴더를 검사해 이름에 포함된 `%` 문자를 Electron이 파일 URL에서 잘못 처리하는 현상을 재현했습니다. 파일 경로를 올바르게 URL로 변환하도록 수정하고, 원클릭 실행에서 빌드된 화면 파일을 직접 열도록 변경했습니다.
- 화면을 이동할 때 스크롤을 맨 위로 돌리고, 최소 창 높이에서도 하단 안내가 보이도록 수정했습니다. npm 의존성이 설치된 경우에도 1단계 범위 검사가 올바르게 동작하도록 테스트를 수정했습니다.
- Windows에서 원클릭 실행과 종료, 네 화면 이동, 언어 전환, 움직임 줄이기, 3D와 예시 입력, AI 제작 버튼 비활성화를 확인했습니다. 자동 검사 16개와 TypeScript·Vite 빌드를 통과했습니다. NSIS 설치 파일을 빌드하고 압축 해제된 패키지를 실행했습니다. 설치 마법사 실행은 검증하지 않았습니다.
- 현재 소스, 테스트, 문서와 이 기록을 비공개 GitHub 저장소에 최초로 보관하도록 사용자가 승인했습니다.

## 2026-11-20 — 2단계 전 1단계 보완

- 1단계 점검에서 나온 Electron 의존성, 개발 모드 실행, Node.js 최소 버전, 화면 자동 검사를 보완했습니다.
- Electron을 45.4.1로 갱신했습니다. 패키지에서는 개발 서버 설정을 무시하고 화면의 네트워크 연결을 차단합니다. 앱 정보 IPC는 로드한 화면의 최상위 프레임으로 제한했습니다.
- 폴더 이름에 공백과 `%`가 있어도 개발 모드에서 화면이 로드되도록 수정했습니다. 창을 정상적으로 닫으면 종료 코드 0으로 종료되고 Vite 포트가 해제됩니다. 포트가 사용 중일 때는 충돌을 알리고 창을 열기 전에 종료합니다.
- 두 Windows 배치 파일에서 Node.js 22.12.0 이상을 검사합니다. 첫 실행이나 잠금 파일 변경 시 `npm ci`를 수행합니다. 한국어 화면에 남아 있던 영어 안내를 번역했습니다.
- `npm run check`와 Windows Electron `npm run test:smoke`를 통과했습니다. 이번 `npm audit` 결과는 알려진 취약점 0건이며 일부 하위 패키지의 지원 종료 경고는 남아 있습니다.
- 새 경로에서 원클릭 설치·실행·종료와 NSIS 빌드를 확인했습니다. 압축 해제된 앱을 실행해 화면과 읽기 전용 앱 정보 연결을 확인했습니다. 설치 마법사 실행은 별도 검증 항목입니다.
- Windows 자동 스모크 테스트는 검증용 창을 표시하지 않고 실행합니다. 임시 프로필에서 화면과 입력을 확인하고 자동 종료하는 것을 재검증했습니다.
- 2단계 개발은 사용자 승인 대기 상태입니다.
