# AI Game Hub 개발 기록

## 현재 범위

Electron, React, TypeScript로 만드는 Windows 게임 제작 플랫폼입니다. 이 기록은 기본 UI, Ollama 연동, Godot 템플릿 제작, AI 자유 제작까지의 결정과 Windows 검증 결과를 정리합니다. 아래 구현과 검증은 로컬 개발본을 기준으로 합니다.

## 2026-11-20 — 요구사항 대화에서 Windows 실행 검증까지

- 기존 ChatGPT 대화에서 요구사항 분석, 아키텍처, 단계별 로드맵과 1단계 완료 기준을 정리했습니다. 자세한 내용은 [설계 문서 모음](README.md)에 있습니다.
- 1단계에 홈, AI 게임 만들기, 내 게임, 설정을 구현했습니다. 제작 화면에서 2D·3D 선택과 예시 입력을 체험할 수 있으며, AI 제작 버튼은 준비 중 상태입니다.
- Windows 원클릭 실행 중 `ERR_FILE_NOT_FOUND`와 검은 화면이 보고되어 개발 서버로 우회했습니다. Codex에서 동일한 폴더를 검사해 이름에 포함된 `%` 문자를 Electron이 파일 URL에서 잘못 처리하는 현상을 재현했습니다. 파일 경로를 올바르게 URL로 변환하도록 수정하고, 원클릭 실행에서 빌드된 화면 파일을 직접 열도록 변경했습니다.
- 화면을 이동할 때 스크롤을 맨 위로 돌리고, 최소 창 높이에서도 하단 안내가 보이도록 수정했습니다. npm 의존성이 설치된 경우에도 1단계 범위 검사가 올바르게 동작하도록 테스트를 수정했습니다.
- Windows에서 원클릭 실행과 종료, 네 화면 이동, 언어 전환, 움직임 줄이기, 3D와 예시 입력, AI 제작 버튼 비활성화를 확인했습니다. 자동 검사 16개와 TypeScript·Vite 빌드를 통과했습니다. NSIS 설치 파일을 빌드하고 압축 해제된 패키지를 실행했습니다. 설치 마법사 실행은 검증하지 않았습니다.
- 현재 소스, 테스트, 문서와 이 기록을 비공개 GitHub 저장소에 최초로 보관하도록 사용자가 승인했습니다.

## 2026-11-20 — 2단계 전 1단계 보완

- 1단계 점검에서 나온 Electron 의존성, 개발 모드 실행, Node.js 최소 버전, 화면 자동 검사를 보완했습니다.
- Electron을 45.4.1로 갱신했습니다. 패키지에서는 개발 서버 설정을 무시하고 화면의 네트워크 연결을 차단합니다. 앱 정보 IPC는 로드한 화면의 최상위 프레임으로 제한했습니다.
- 폴더 이름에 공백과 `%`가 있어도 개발 모드에서 화면이 로드되도록 수정했습니다. 창을 정상적으로 닫으면 종료 코드 0으로 종료되고 Vite 포트가 해제됩니다. 포트가 사용 중일 때는 충돌을 알리고 창을 열기 전에 종료합니다.
- 두 Windows 배치 파일에서 Node.js 22.12.0 이상을 검사합니다. 첫 실행이나 잠금 파일 변경 시 `npm ci`를 수행합니다. 한국어 화면에 남아 있던 영어 안내를 번역했습니다.
- `npm run check`와 Windows Electron `npm run test:smoke`를 통과했습니다. 이번 `npm audit` 결과는 알려진 취약점 0건이며 일부 하위 패키지의 지원 종료 경고는 남아 있습니다.
- 새 경로에서 원클릭 설치·실행·종료와 NSIS 빌드를 확인했습니다. 압축 해제된 앱을 실행해 화면과 읽기 전용 앱 정보 연결을 확인했습니다. 설치 마법사 실행은 별도 검증 항목입니다.
- Windows 자동 스모크 테스트는 검증용 창을 표시하지 않고 실행합니다. 임시 프로필에서 화면과 입력을 확인하고 자동 종료하는 것을 재검증했습니다.
- 2단계 개발은 사용자 승인 대기 상태입니다.

## 2026-11-20 — 2단계 로컬 AI 구현 및 3중 검증

- 이용자 승인 후 기존 네 화면을 유지한 채 로컬 AI 채팅을 추가했습니다. PC 사양 및 Ollama 상태 확인, 모델 추천·선택, 다운로드 동의·진행, 채팅 스트리밍·중지·재시도를 구현했습니다.
- 사용하지 않는 아이콘 정의 8개와 고정 앱 버전 표시를 정리했습니다. 화면 동작을 중복으로 확인하던 소스 패턴 검사는 숨김 Electron 실행 검사로 확인하도록 정리했습니다.
- 자동 검사 27개와 빌드, 숨김 Windows 테스트, 독립 검토를 완료했습니다. 독립 검토에서 찾은 모델 충돌 가능성과 느린 저장장치의 취소 지연을 보완했습니다.
- 설치돼 있던 7B 모델로 실제 스트리밍, 중지, 중지 후 재요청을 확인했습니다. 새 모델의 실제 다운로드는 진행하지 않았습니다. 측정값과 남은 항목은 [2단계 로컬 AI 검증 기록](10_phase2_local_ai.md#검증-기록)에 있습니다.

## 2026-11-20 — 2D·3D 미리보기 구분

- 같은 달빛 폐허 예시를 2D 횡스크롤 시점과 3D 원근 카메라로 그렸습니다. 선택 버튼과 미리보기 설명에 카메라와 이동 방향의 차이를 표시합니다.
- 제작 화면에서 이용할 수 있는 로컬 AI 채팅을 강조하고, 게임 파일 생성과 실행은 3단계 예정임을 표시합니다.
- 자동 검사 27개와 프로그램 빌드를 통과했습니다. 숨김 Windows 실행에서 2D→3D→2D 전환과 로컬 AI 채팅을 재검증했고, 최소 창 크기에서 두 미리보기가 잘리지 않는 것을 확인했습니다.

## 2026-11-20 — 1·2단계 정리와 3단계 개발

- 기존 네 화면과 로컬 AI 채팅을 먼저 검증했습니다. 중복 원클릭 검사, 비활성화된 제작 UI와 오래된 단계 문구를 정리했습니다. 기존 설계 문서는 보존했습니다.
- 서명 검증한 Godot 4.7.2를 로컬에 준비하고 2D 횡스크롤, 3D 발판 게임을 구현했습니다. 로컬 AI가 정한 설정을 Godot에서 검증한 후 저장하며 내 게임에서 플레이·수정·복원할 수 있습니다.
- 자동 검사 36개, 실제 Ollama 및 숨김 Windows·Godot 실행, 독립 리뷰를 완료했습니다. 조건 조합 18개와 입력으로 완주하는 검사 6개를 추가로 확인했습니다. [3단계 검증 기록](11_phase3_game_creation.md#세-차례-검증)

## 2026-11-20 — 앱 안에서 게임 플레이

- 미리 플레이가 별도 창을 여는 경로를 Godot Web 기반의 앱 내 플레이로 바꿨습니다. 로딩과 오류 안내, 다시 시도, 게임 닫기를 추가했습니다.
- 실제 2D·3D 게임을 숨김 Windows Electron에서 같은 창으로 시작하고, 게임 프레임에서 앱 IPC에 접근할 수 없는 것을 확인했습니다.

## 2026-11-20 — 실제 사용자 흐름 개선

- 홈에서 실제 2D·3D 예시를 시작하거나 초안을 이어가고, 생성 뒤 바로 같은 창에서 플레이하도록 개선했습니다. 준비 상태와 다시 확인을 추가했습니다.
- 내 게임에 검색·형식 필터, 준비 취소, 플레이 포커스, 복원 확인을 추가했습니다. 채팅에 Enter 전송, 예시 질문, 새 대화 확인을 추가했습니다. 언어와 움직임 줄이기 설정을 저장합니다.
- 미리보기 종료·취소·새로고침 시 정리 흐름을 보완했습니다. Godot Web에서 한글 제목이 네모로 표시되는 문제를 확인하고 나눔고딕과 라이선스를 포함했습니다.
- 자동 검사 45개와 빌드, 숨김 Windows 사용자 흐름, 실제 2D·3D 앱 내 플레이를 재검증했습니다.

## 2026-11-20 — 제작 설정 확장과 0.3.0 안내

- 외부 리뷰에서 지적한 문서와 런처 안내를 실제 3단계 기능에 맞췄습니다. 앱과 잠금 파일 버전을 0.3.0으로 맞추고, 준비 상태에서 공식 다운로드와 Godot 폴더를 열도록 했습니다.
- 직접 설정을 추가해 Godot이 준비되면 Ollama 없이도 새 게임을 만들 수 있습니다. 채팅 내용을 기존 초안과 별도로 검토하고, 수정 후 저장할 수 있습니다. 최근 완료 대화의 이 PC 저장은 선택 사항입니다.
- 2D·3D에 밤하늘·숲·우주, 이동·점프 프리셋, 첫 조작부터 클리어까지 걸린 시간과 해당 플레이 세션의 최단 기록을 추가했습니다. 기존 저장 파일의 기본 설정을 보존합니다.
- 자동 검사 50개, 빌드, 숨김 Electron에서 대화 기록 재로드·설정 가져오기·Ollama 오프라인 제작과 실제 Ollama·Godot 2D·3D Web 내보내기·수정·복원을 검증했습니다. 프리로드·보안·설치 안내 코드에 타입 검사를 추가했습니다.
- Godot 실행 파일과 Web 템플릿은 공식 배포에서 직접 준비합니다. 이번 변경은 로컬에 적용했고 개발 기록과 함께 업로드하려면 사용자 승인을 받습니다.

## 2026-11-21 — AI 자유 제작

- 사용자가 장르와 규칙을 정하는 별도 제작 모드를 추가했습니다. 빈 프로젝트에서 Ollama에 첫 버전을 요청하고, 앱 안에서 플레이한 다음 대화로 수정합니다. 기존 Godot 템플릿은 별도로 사용할 수 있습니다.
- 모델 출력은 제한된 데이터 형식으로 받고 메인 프로세스에서는 문법만 검사합니다. 게임 코드는 격리된 브라우저 작업 스레드에서 실행합니다. 파일, 네트워크와 앱 연결은 차단하며, 초기 프레임 검사에 실패한 후보는 폐기합니다.
- 자유 제작 프로젝트와 제작 대화는 로컬에 저장합니다. 수정 결과는 초기 실행 확인 후에만 이전 파일을 원자적으로 교체하고 직전 버전을 보관합니다. 앱을 닫을 때 진행 중인 저장을 기다립니다.
- 자동 검사 58개와 빌드, 숨김 Electron의 제작·조작·수정 실패·취소·복원·재열기, 기존 2D·3D Godot 실행을 검증했습니다. 실제 로컬 7B 모델은 방향키 게임과 클릭 게임을 생성했고, 색만 바꿔 달라는 수정 요청도 반영했습니다. 더 복잡한 요청에서 규칙 일부가 빠지는 경우도 확인했습니다.

## 2026-11-21 — 사용설명서와 개발 기록 정리

- Windows 실행, 자유 제작, 같은 창 플레이, 대화로 수정하기를 안내하는 빠른 사용설명서를 정리했습니다.
- 승인된 GitHub 보관 범위는 이 개발 기록과 [로컬 AI 검증 기록](10_phase2_local_ai.md), [Godot 템플릿 검증 기록](11_phase3_game_creation.md)입니다. 새 기능의 소스와 실행 파일은 로컬 개발본에 있습니다.

## 2026-11-21 — 자유 제작 레이싱과 수정 요청 보완

- 레이싱 예시에서 AI가 두 번 같은 코드를 반환한 것을 확인했습니다. WASD가 연결되지 않았고, 트랙은 화면 테두리였으며 랩을 올리는 로직이 없었습니다.
- 사용자 레이싱 프로젝트는 야간 순환 트랙, 세 대의 상대 차량, WASD·Space 드리프트, 체크포인트 기반 2랩으로 복구했습니다. 기존 저장은 복원할 수 있도록 보존했습니다.
- AI에 실패한 동작을 설명하면 기존 코드와 첫 게임 요구사항을 비교해 수정 항목을 정리합니다. 핵심 기능이 빠졌으면 이전 코드 대신 요구사항을 바탕으로 재작성할 수 있습니다. 기존 코드와 같은 결과나 잘못된 키 코드는 재검토합니다. 실행에 실패한 수정본은 저장하지 않고, 실패한 코드로 실행 오류를 수정할 수 있습니다.
- 숨김 Electron에서 게임의 키보드 포커스와 W·D+Space 동시 입력, Esc 키 해제, 실패 후 수정·저장을 검증했습니다. 레이싱 복구판은 순서대로 체크포인트를 통과해 두 바퀴를 완주하는 것을 별도로 확인했습니다.

## 2026-11-21 — 짧은 게임 요청 보강과 단일 HTML 저장

- 간단한 한국어·영어 장르 요청에 조작, 진행, 승패 조건을 보강합니다. 상세한 요청과 게임 수정에서는 사용자가 정한 조건과 대화 기록을 우선합니다.
- 짧은 요청의 모델 응답에서 레이싱의 랩·상대 차량 누락과 별 수집의 연속 이동·즉시 초기화 오류를 찾아 재생성을 요청합니다. 이 소스 검사는 전체 플레이를 검증하지 않습니다.
- 자유 제작 게임에서 **HTML로 저장**을 추가했습니다. 저장한 JavaScript와 검증된 실행기를 한 파일에 넣으며, 별도 서버 없이 브라우저에서 열 수 있습니다.
- 자동 검사 71개와 빌드, 숨김 Electron에서 HTML 저장과 기존 제작 흐름, Chrome에서 오프라인 HTML의 키 입력을 확인했습니다. 실제 7B 응답에서 확인한 레이싱 누락과 별 수집 오류를 소스 검사로 잡는 것을 점검했습니다.

## 2026-11-21 — Ollama 자유 제작 응답 복구

- 기본 JSON과 Markdown 안의 JSON·JavaScript, 설명과 함께 온 JavaScript에서 완결된 게임 코드를 추출합니다. 구문만 검사한 뒤 기존 격리 미리보기에 전달합니다.
- 시스템 프롬프트와 장르 지시를 줄였습니다. 형식 복구가 안 되거나 출력이 잘리면 두 번째 시도에서 JSON 강제를 풀고 완성된 JavaScript 함수를 요청합니다.
- 장르 검사는 한 차례 재시도에 사용하는 보완 의견으로 다룹니다. 재시도에서 적합한 코드가 나오지 않으면 문법과 기본 입력을 통과한 초안을 유지합니다.
- 앱을 실행한 터미널에 자유 제작 실패 시도 번호, 사유, Ollama HTTP 상태와 원본 응답을 출력합니다.
- 자동 검사 79개, 빌드와 숨김 Electron 스모크 테스트를 통과했습니다. 실제 로컬 7B가 새로 생성한 레이싱·별 수집 코드를 격리된 실행기에서 열었습니다. 자동 생성본에는 일부 경기 규칙이나 실제 종료 처리가 빠져 있었습니다.

## 2026-11-21 — 제작 화면을 AI 대화로 통합

- 홈과 제작 메뉴의 템플릿 제작 화면을 정리했습니다. 이제 **AI 게임 만들기**에서 바로 제작 대화를 시작하며, 이전에 만든 Godot 게임은 **내 게임**에서 엽니다.
- Ollama 준비 화면에는 모델 준비만 남겼습니다. 게임의 요청, 미리보기, 수정은 하나의 제작 대화에서 이어집니다.
- 첫 실행에 실패한 코드를 AI가 그대로 되돌려 주면 그 코드를 다시 보내지 않고, 원래 게임 설명과 제작 맥락에서 재생성을 요청합니다. 빈 프로젝트에서 반복 코드 오류가 발생하면 저장된 버전이 있다는 안내를 표시하지 않습니다.
- 자동 검사 80개와 빌드, 숨김 Windows 앱 검사 두 종류를 통과했습니다. 실제 로컬 모델에 실행이 실패하는 장애물 피하기 초안을 주어 새 코드를 생성하고 격리된 미리보기에서 시작되는 것을 확인했습니다.

## 2026-11-22 — 복합 게임 5개로 로컬 모델 비교

- 3차선 자동차, 전등 퍼즐, 배달, 리듬, 포탑 방어를 같은 한국어 요청으로 각각 처음 제작하고 수정했습니다. RTX 4060 Ti 8GB에서 Qwen2.5-Coder 7B와 Qwen3 8B에 총 20개 실제 Ollama 요청을 보냈습니다.
- 양쪽 모두 게임 소스 10개씩을 반환했습니다. 숨김 Electron 미리보기는 Qwen2.5-Coder 7B가 첫 제작과 수정에서 각각 4/5, Qwen3 8B가 각각 5/5 열렸습니다. 요청당 평균은 각각 24.3초와 82.3초였습니다.
- 전체 조작·진행·승패 기준을 충족한 후보는 없었습니다. Qwen3 8B의 자동차 수정본은 10초 뒤 가속을 구현했지만 차선 조작은 여전히 달랐고, 온실 퍼즐은 클릭한 전등 하나만 바뀌었습니다. 비교는 별도 작업 폴더에서 실행했습니다.
- 프롬프트와 판정 내역을 로컬 비교 보고서에 정리했고, 미리보기가 열린 HTML 18개를 비교용 결과로 묶었습니다.

## 2026-11-23 — 기본 모델을 Qwen3 8B로 변경 및 인수인계

- 사용자 요청에 따라 자유 제작은 설치와 모델 지문을 확인한 Qwen3 8B를 먼저 사용합니다. 모델을 준비하는 동안 설치된 Qwen2.5-Coder를 사용할 수 있습니다. Qwen3 요청에는 `think: false`를 적용합니다.
- 자동 검사 82개와 빌드, 숨김 Electron 기본 흐름과 자유 제작 스모크 테스트를 통과했습니다. 실제 Ollama에서는 앱의 기본 선택이 Qwen3 8B로 요청을 보내고 동전 클릭 게임 코드를 받아오는 것을 확인했습니다.
- 계정이 달라져도 이어서 개발할 수 있도록 실행, Git 복원, 새 개발 대화용 요약을 [인수인계 문서](HANDOFF.md)에 남겼습니다.

## 2026-11-26 — 자유 제작 진행 상태와 화면 이동 유지

- 자유 제작이 진행되는 동안 제작 버튼과 입력창을 비활성화하고, 현재 단계의 예상 진행률을 퍼센트와 막대로 표시합니다. 코드 생성 구간은 실제 완료 신호가 오기 전 70%까지만 증가하며, 미리보기 확인과 저장 단계에서 80%와 95%를 표시합니다.
- 다른 앱 화면으로 이동해도 로컬 AI의 생성 요청을 취소하지 않도록 바꿨습니다. 제작 화면으로 돌아오면 진행 중인 요청, 비활성 버튼과 기존 게임 미리보기를 다시 연결합니다. 사용자가 **중지**를 누르거나 앱이 종료되면 기존 취소 처리를 사용합니다.
- 자동 검사 82개와 숨김 Electron 자유 제작 검사에서 진행률, 중복 생성 차단, 화면 이동 후 작업 유지, 취소, 저장과 복원을 확인했습니다.
