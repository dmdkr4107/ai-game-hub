# 10. 2단계 로컬 AI

## 사용 방법

- `START_AI_GAME_HUB.bat`을 실행하고 **AI 게임 만들기 → 로컬 AI 채팅**으로 이동합니다.
- Ollama가 응답하지 않으면 [Ollama Windows 안내](https://ollama.com/download/windows)에 따라 실행한 뒤 앱에서 다시 확인합니다.
- PC 사양과 권장 모델을 확인하고 선택합니다. 지원 모델의 예상 크기와 라이선스는 [Qwen2.5-Coder Ollama 모델 목록](https://ollama.com/library/qwen2.5-coder)에 기반합니다.
- 설치되지 않은 모델만 다운로드 동의가 필요합니다. 앱이 표시하는 경로는 앱 환경에서 확인한 `OLLAMA_MODELS` 또는 기본 모델 폴더입니다. Ollama가 별도 계정이나 환경 설정으로 실행 중이면 실제 경로가 다를 수 있습니다.
- **이 PC에 대화 저장**을 켜면 최근 완료된 대화를 이 앱의 로컬 프로필에 저장합니다. 기본값은 꺼짐이며, 옵션을 끄거나 **새 대화**로 기록을 지울 수 있습니다.
- 답변이 끝난 뒤 **이 내용으로 게임 설정 채우기**를 누르면 대화에서 설정을 추출합니다. 제작 화면에서 2D·3D와 제목, 별, 난이도, 테마, 이동을 확인하고 수정할 수 있습니다.

## 구현 경계

- Electron 메인 프로세스에서만 고정된 `127.0.0.1:11434`의 Ollama API를 사용합니다. 렌더러 격리와 외부 연결 차단을 유지하고, 허용된 최상위 화면에만 IPC를 제공합니다.
- Ollama의 설치 모델 목록과 모델 정보를 확인합니다. 앱이 지원하는 매니페스트와 일치하는 로컬 모델만 사용합니다. 크기는 다운로드 전 예상값으로 표시합니다. Ollama를 사용하는 다른 프로그램이 같은 태그를 동시에 바꿀 수 있으므로 다운로드 직전과 직후에 모델을 다시 확인합니다.
- 모델 추천은 RAM과 VRAM을 기준으로 표시합니다. 저장 여유 공간은 다운로드 직전에 별도로 확인합니다. 대상 PC에서 실제 처리 속도와 메모리 사용량을 확인한 뒤 기본값을 정합니다.
- 요청 길이와 작업 시간을 제한하고 한 번에 하나의 작업을 처리합니다. 취소하거나 창이 닫히면 앱의 요청을 중단합니다. 다운로드 중 확보한 일부 데이터는 Ollama가 재시도를 위해 보관할 수 있습니다.
- 채팅 응답은 텍스트로 표시합니다. 설정으로 가져올 때 Ollama의 구조화된 출력으로 제한하고, 앱에서 설정 값을 검증합니다. 게임 생성과 실행은 [3단계 제작 흐름](11_phase3_game_creation.md)에서 제공합니다. [Ollama 구조화된 출력 문서](https://docs.ollama.com/capabilities/structured-outputs)

## 검증 기록

| 검증 | 결과 |
|---|---|
| 1. 자동 검사와 빌드 | `npm run check`에서 27개 통과. 모델 제한, 스트림, 오류·타임아웃, 취소·재시도, IPC, 모델 충돌과 저장 공간 확인을 포함합니다. `npm audit`에서 알려진 취약점 0건을 확인했습니다. |
| 2. 숨김 Windows 실행 | `npm run test:smoke`가 기존 네 화면과 로컬 채팅 흐름을 확인했습니다. 모의 응답으로 모델 선택, 다운로드 동의·거절·진행률, 연결 끊김을 재현했습니다. 실제 Ollama와 설치된 7B 모델로 스트리밍, 중지, 중지 후 재요청도 통과했습니다. |
| 3. 독립 검토와 재검증 | 고정 루프백 연결, 모델 식별, IPC의 호출자와 종료 처리를 별도 검토했습니다. 다운로드 직전 모델 목록을 다시 확인하고, 느린 디스크 조회 중에도 취소할 수 있도록 수정했습니다. 별도 검토에서 백엔드 검사 14개가 통과했습니다. |

### 실제 Windows 측정

이 PC의 RTX 4060 Ti 8 GiB에서 `qwen2.5-coder:7b`로 측정했습니다. 한 번의 최종 실행에서 첫 출력까지 약 **3.8초**, 짧은 응답 완료까지 약 **4.0초**, 취소 명령 후 앱 요청이 종료되기까지 약 **1ms**가 걸렸습니다. 취소 후 다음 요청도 정상 완료했습니다. 측정 중 시스템 전체의 GPU 메모리 사용량은 3,059 MiB에서 최대 7,606 MiB, RAM 사용량은 18,314 MiB에서 최대 19,658 MiB였습니다. 요청 종류와 모델의 로드 상태, 다른 프로그램 사용량에 따라 달라집니다.

Windows 설치 파일을 빌드하고 패키지의 로컬 AI 백엔드, IPC, 프리로드와 렌더러 파일이 검증한 소스 및 빌드와 일치하는 것을 확인했습니다.

새 모델의 실제 다운로드는 수행하지 않았습니다. 1.5B 모델은 모의 다운로드 흐름에서 검증했습니다. Windows 설치 마법사 실행과 다른 PC 사양에서의 실측도 남아 있습니다.
