# 01. 요구사항 검토

## 해석 원칙
원문 v0.2의 상태 체계: **확정**(제품 방향), **제안**(개발 권장), **검증 필요**(실측/법률 검토), **결정 필요**(추가 사용자 선택). 원문 P0/P1/P2는 **출시 범위**이며, 본 프로젝트의 구현 1~5단계와 동일하지 않다.

## 이미 확정된 정책 — 그대로 유지
- Windows PC 설치형, 일반 사용자와 전 연령 지향, 글로벌 서비스 목표(출시국 세부 미정)
- 모든 기능 로그인·인터넷 필수, 이메일+Google 인증
- 로컬 AI, PC 사양 기반 모델 자동 추천 및 수동 선택
- 자유 제작/템플릿 제작, 자동 제작/쉬운 단계별 제작, 자연어 생성/수정
- 2D·3D 둘 다 지원(시작은 각각 플레이 가능한 최소 장르 1종)
- 로컬 프로젝트 저장, 선택적 클라우드 백업
- 비공개/친구/전체 공개, 모든 공유 게임 무료, 허용 기반 리믹스
- 친구 및 공개 멀티플레이 방, 텍스트 채팅
- 연령별 보호자 동의·콘텐츠 제한/검사, 신고 및 차단
- 허브 외부 실행 파일 내보내기/배포 기능 제공하지 않음
- 수익화 방식은 미정

## 긴장 관계 및 해결 제안
1. **로그인·인터넷 필수 vs 1단계 로그인 없는 UI**: 1단계는 내부 개발 전용 스캐폴드이며 최종 사용자 기능은 잠금 상태. 4단계 인증 완성 전 공개 배포 금지. 최종 제품 정책의 예외가 아님.
2. **P0 내부 시제품에 로그인 시험 vs 인증 기능은 개발 4단계**: 로그인 연동의 최소 시험 시점을 3단계 종료 전으로 앞당기는 게 합리적이나 이는 일정 변경이므로 승인 전에는 4단계 유지. 단계 3 종료 시 서비스 출시 가능이라고 판단하지 않는다.
3. **상시 인터넷 vs 로컬 보존**: 작업 지속은 제한하되 임시 파일을 안전하게 확정/복구. 오프라인 플레이를 제공한다는 의미가 아님.
4. **'게임 제작 2D·3D' vs AI 품질**: 템플릿·허용 API·검증 가능한 작업을 우선, 지원 불가 요구는 명확히 고지.
5. **게임은 허브 내 실행 vs 로컬 프로젝트 파일**: 파일이 디스크에 존재함과 정식 외부 실행/배포 기능을 제공하지 않음은 별개. DRM/완전한 외부 실행 차단을 보장하지 않는다.
6. **모든 연령 글로벌 출시 vs 채팅/UGC**: 국가별 연령·동의·등급·모더레이션 체계 없이는 지역·기능 출시를 보류.
7. **무료 공유 vs 비용**: 광고·구독 등 수익화를 임의 결정하지 않음. 원가 계측 후 결정.

## 범위 제한
- 자동 3D 에셋 생성·모든 장르 지원·일반 코드를 안전하게 실행할 수 있음을 약속하지 않는다.
- 권리·연령·등급의 법적 결론을 내리지 않는다.
