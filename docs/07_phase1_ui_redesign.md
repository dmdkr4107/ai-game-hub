# 07. 1단계 UI 디자인 개선 기록

- 작성일: 2026-11-18
- 범위: **1단계 Electron + React 앱의 디자인 및 화면 데모 기능만 수정**
- 원본: `AI_Game_Hub_1단계_원클릭실행_추가.zip`
- 기존 `docs/01~06`, 배치 파일, Electron 보안 및 읽기 전용 IPC는 유지

## 변경 내용

| 화면 | 적용한 디자인 | 실제 동작 |
|---|---|---|
| 홈 | 어두운 퍼플/네이비 게임 허브, 큰 히어로 배너, 코드 기반 아트, 콘셉트 카드 | 메인 메뉴/빠른 이동 버튼 |
| AI 게임 만들기 | 제작 단계 표시, 2D/3D 콘셉트 선택, 자연어 아이디어 입력, 입력 예시 | 텍스트 입력, 2D/3D UI 토글, 예시 입력. 생성 버튼은 비활성화 |
| 내 게임 | 프로젝트 현황(0개), 일러스트 빈 상태 | 게임 만들기 화면으로 이동. 프로젝트 저장/로드 없음 |
| 설정 | 언어/테마/애니메이션 안내, 버전/안전 고지 | 한국어/영어 전환, 장식 애니메이션 줄이기. 테마 선택은 구현 안 됨 |

색상은 다크 배경, 보라색 포인트, 밝은 남색 카드에 기반하며, 새로운 이미지/아이콘 다운로드 없이 **CSS + 인라인 SVG**로 구성했다. 외부 폰트/CDN/이미지 의존성은 추가하지 않았다.

## 구현 범위와 한계

- 자유 작성 프롬프트는 UI 안에서만 상태가 유지된다. 서버나 AI 전송 및 디스크 저장 기능 없음.
- 2D/3D 버튼은 디자인 시연용 상태 변경이며, 실제 Godot 생성이나 게임 실행을 하지 않는다.
- 하단 콘셉트 카드 3개는 설명용 일러스트이며 실제 게임 목록이나 실행 가능한 콘텐츠가 아니다.
- 로그인, Google, Ollama, Godot, SQLite, 클라우드, 공유, 친구, 채팅, 멀티플레이 등의 **2단계 이후 기능은 추가하지 않았다.**
- 상시 로그인/온라인 정책은 서비스 정책으로 유지되지만 이 빌드는 *내부 화면 개발용*이라 인증 없이도 볼 수 있으며 외부 배포해서는 안 된다.

## 검증

- Node.js의 기본 테스트: `npm test` (기존 8개 + 신규 UI 리디자인 4개 = 12개)
- TypeScript 앱/다국어 TSX/TS 소스 구문 검증은 현재 환경의 TypeScript 컴파일러로 별도 수행.
- 컴포넌트 JSX를 정적으로 렌더링하고 **같은 CSS**를 적용한 HTML의 Chromium 화면을 4개 캡처하여 `previews/`에 저장. 레이아웃 확인용이며 React 이벤트/앱 작동을 검증하는 테스트가 아니다.
- `npm install` 시도는 이 실행 환경의 DNS `EAI_AGAIN registry.npmjs.org`로 실패. 따라서 `npm run build`, 실제 Electron 실행, Windows 설치 파일/원클릭 실행 테스트는 **미검증**.
- Windows에서 `START_AI_GAME_HUB.bat`을 사용해 빌드·실행한 후 키보드/마우스 검증을 실시해야 1단계 완료로 판단할 수 있다.

## Windows 검증 체크리스트

1. 압축을 풀고 `START_AI_GAME_HUB.bat` 더블클릭. Node.js LTS/인터넷 연결은 최초 설치에 필요.
2. 홈에서 게임 만들기 화면으로 이동, 사이드바 네 메뉴 왕복.
3. 제작 화면 2D/3D 선택, 예시 문장 입력, 1000자 제한, 생성 버튼 비활성화 확인.
4. 설정에서 한국어/영어 전환 및 움직임 줄이기 확인.
5. 최소 900×620 창 크기에서 깨지는 레이아웃 없는지, 전 화면 스크롤 가능한지 확인.
6. `npm test` 및 `npm run build` 성공 여부와 에러 메시지를 기록.

**검증 결론:** UI 소스/정적 시안 및 자동 소스 검사를 준비했다. Windows 실기 실행은 미검증이므로 전체 1단계 완료 상태가 아니다.
